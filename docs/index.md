## Where to start

This site serves three reader clusters. Pick the one that fits the current task:

* **Adoption.** Wire a module into a consumer project, pick a pin, tune the variables. Continue with the Usage section below, then open the matching [module page](modules/mkdocs.md).
* **Contribution.** Add a module, change an existing task, or update the rendered docs. Jump to the [Contributing page](contributing.md).
* **Governance and conformance.** Check that the repository still satisfies the portfolio specs (project structure, release automation, Renovate, Vale). Jump to the [Governance page](governance.md).

[`AUDIENCES.md`](https://github.com/nolte/taskfiles/blob/main/AUDIENCES.md) records the audience analysis behind this structure.

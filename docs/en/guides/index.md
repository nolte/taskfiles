# Guides

Task-oriented how-tos for contributors. Each guide assumes a reader who
already knows the basics from
[Getting Started](../getting-started/index.md) or the
[module references](../references/index.md).

## Available guides

- [Contributing](contributing.md): add a module, change an existing task, or
  update the rendered docs. Covers module conventions, documentation
  conventions, local checks, and the pull-request flow.

The list is intentionally short. The repository is small, and most
contributor questions resolve against [`CLAUDE.md`](https://github.com/nolte/taskfiles/blob/main/CLAUDE.md)
or the [References](../references/index.md) section.

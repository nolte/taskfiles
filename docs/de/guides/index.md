# Anleitungen

Aufgaben-orientierte How-tos für Mitwirkende. Jede Anleitung setzt voraus,
dass die Grundlagen aus
[Erste Schritte](../getting-started/index.md) oder den
[Modul-Referenzen](../references/index.md) bekannt sind.

## Verfügbare Anleitungen

- [Mitwirken](contributing.md): ein Modul hinzufügen, einen bestehenden
  Task ändern oder die gerenderte Doku aktualisieren. Abdeckung von
  Modul-Konventionen, Doku-Konventionen, lokalen Prüfungen und dem
  Pull-Request-Ablauf.

Die Liste ist absichtlich kurz. Das Repository ist klein, und die meisten
Fragen von Mitwirkenden lassen sich über
[`CLAUDE.md`](https://github.com/nolte/taskfiles/blob/main/CLAUDE.md) oder
die [Referenzen](../references/index.md) klären.
